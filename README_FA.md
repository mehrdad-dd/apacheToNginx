## هشدار فنی و امنیتی

> [!CAUTION]
> **این نسخه را روی سرور عملیاتی اجرا نکنید.** در اسکریپت یک کوتیشن بسته‌نشده نزدیک `DEFAULT_SSL_KEY_PATH` دیده می‌شود. گزینه معرفی‌شده `--dry-run` پردازش نمی‌شود و بخش‌هایی از کد امکان جابه‌جایی یا جایگزینی فایل‌های تنظیمات Nginx را دارند. تا زمان بازبینی و تست ایمن، آماده استفاده عملی نیست.

برای بررسی نحو، بدون اجرای عملیات تبدیل:

```bash
git clone https://github.com/mehrdad-dd/apacheToNginx.git
cd apacheToNginx
bash -n converter.sh
```

آزمون `bash -n` در وضعیت فعلی خطای نحوی نشان می‌دهد. رفع خطا، پیاده‌سازی Dry Run واقعی و تست نمونه‌های ساختگی باید در بازنگری فنی جداگانه انجام شود.
