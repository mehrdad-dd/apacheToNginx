# Contributing

This repository is an attributed, upstream-derived copy of [razamoh/apacheToNginx](https://github.com/razamoh/apacheToNginx). Contributions must preserve the original author's credit and the full existing license text.

- Explain the exact file(s) changed, motivation, and testing.
- Do not claim ownership of code inherited from upstream.
- Do not introduce proprietary code or content without compatible permission.
- Treat license status conservatively: `LICENSE` contains GPLv3, historical README claimed MIT; see [PROVENANCE.md](PROVENANCE.md).
- Never include real host configurations, keys, passwords, or internal domain names.
- Do not run conversion on production infrastructure until reviewed dry-run semantics, rollback, and automated tests are in place.
